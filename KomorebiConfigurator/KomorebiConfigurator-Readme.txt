=================================================
Komorebi Server Configurator (.NET) 
=================================================

Androidアプリ「Komorebi」から、Windows上のEDCB（EpgTimerSrv）録画ファイルに
直接アクセスするためのサーバー側セットアップ支援ツールです。

-------------------------------------------------
1. 概要
-------------------------------------------------
このツールは、以下の作業を自動化します：

(1) シンボリックリンクの作成
Windowsの「mklink /D」コマンドを使用し、EDCBの HttpPublic フォルダ内に
録画フォルダへのショートカット（シンボリックリンク）を作成します。

(2) Luaスクリプトの生成
Komorebiアプリが録画パスをURLに変換するためのマッピング定義ファイル
「komorebi_resolver.lua」を自動生成し、適切な場所に配置します。


-------------------------------------------------
2. 動作要件
-------------------------------------------------
【実行環境 (ユーザー側)】
- OS: Windows 10 / 11 (x64)
- 権限: 管理者権限（シンボリックリンク作成に必要）
- ランタイム: 不要（自己完結型ビルドの場合）

【開発・ビルド環境】
- OS: Mac (Apple Silicon / Intel) または Windows
- SDK: .NET 8.0 SDK
- IDE: Visual Studio Code (Avalonia for VS Code 拡張推奨)


-------------------------------------------------
3. ユーザーガイド（使い方）
-------------------------------------------------
(1) 基本設定
- 「EDCBの HttpPublic フォルダ」を参照ボタンから選択します。
  （例: C:\EDCB\HttpPublic）

(2) マッピングの追加
- 「録画フォルダ実体」を選択します。
  （例: D:\TV_Rec）
- 「エイリアス名」を入力します（デフォルト: rec）。
- 「リストに追加 / 更新」をクリックします。
- ※複数の物理ドライブを使用している場合は、それぞれ別のエイリアス名で
  追加してください。

(3) セットアップの実行
- 「セットアップ実行」ボタンをクリックします。
- ユーザーアカウント制御（UAC）のダイアログが表示されるので
  「はい」を選択します。
- 完了メッセージが出れば成功です。


-------------------------------------------------
4. 開発者ガイド（ビルド方法）
-------------------------------------------------
Mac環境からWindows用のシングルバイナリ（.exe）を出力する方法です。

[プロジェクトの復元]
dotnet restore

[Windows用バイナリの出力 (自己完結型・トリミング有効)]
dotnet publish -c Release -r win-x64 \
  --self-contained true \
  -p:PublishSingleFile=true \
  -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:PublishTrimmed=true

- 出力先: bin/Release/net8.0/win-x64/publish/KomorebiConfigurator.exe
- ファイルサイズ: 約12MB（トリミング有効時）


-------------------------------------------------
5. 技術仕様
-------------------------------------------------
【配置ファイル】
実行後、以下のディレクトリ構造が構築されます。

HttpPublic/
├── [エイリアス名] (D:\TV_Rec 等へのシンボリックリンク)
└── legacy/
    └── komorebi_resolver.lua (自動生成されたパス変換スクリプト)

【マッピングの仕組み】
komorebi_resolver.lua 内の MAPPING テーブルによって、
EDCBが返す物理パスとHTTP公開用パスの紐付け管理が行われます。

例：
local MAPPING = {
    ["D:\\TV_Rec"] = "rec",
    ["E:\\Anime"] = "anime",
}

【開発時の注意点 (Mac)】
- UIフレームワークとして Avalonia UI を使用しているため、
  Mac上でも dotnet run で画面のプレビューおよびデバッグが可能です。
- ただし、Windows OS固有の mklink コマンドの実行テストは、
  Windows実機または仮想環境が必要です。


-------------------------------------------------
6. ライセンス
-------------------------------------------------

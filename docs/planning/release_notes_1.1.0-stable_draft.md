# Komorebi v1.1.0-Stable リリースノート（ドラフト）

Komorebiの正式版アップデート、v1.1.0-Stableをリリースしました！

1.0.0のリリースから、ご要望の多かった **EDCBバックエンドのフルサポート** と、**EPGStationバックエンド対応** をはじめ、視聴体験全体を底上げする数々の機能追加・改善を行いました。

---

## 🚀 主な新機能

### 📡 マルチバックエンド対応の拡充
* **EDCBバックエンドのフルサポート**
  KonomiTVバックエンドと同等に、チャンネル一覧・番組表・録画予約・リアルタイム視聴・録画再生・ニコニコ実況コメント表示に対応しました。
  * 録画ファイルへの「直接アクセス」再生に対応し、チャプターサーチ、シーンサーチ、シークバー上のサムネイル表示、自動CMスキップが利用可能になりました。
  * EMWUI経由のトランスコード再生にも対応し、ライブ・録画双方で柔軟な画質選択やシークが行えます。二画面モードでの同時トランスコード視聴もサポートしています。
* **EPGStation（stuayu Fork版）バックエンド対応**
  [stuayu氏によるFork版EPGStation](https://github.com/stuayu/EPGStation) をバックエンドとして選択できるようになりました。チャンネル一覧・番組表・録画予約・ライブ視聴・録画視聴・シリーズ情報表示に対応しています。

### 🎞️ KonomiTV「オリジナル」画質対応
ライブ視聴・録画視聴の両方で、トランスコードを介さないオリジナル画質（MPEG-2 TS直接再生）での視聴に対応しました。

### 📂 SMB（ファイルライブラリ）経由の動画視聴
NASや共有フォルダ上の動画ファイルを直接再生できる機能を追加しました。libVLCベースの再生エンジンにより幅広いコンテナ・コーデックに対応し、QRコードを使ったスマートフォンからのサーバー登録や、よく見るフォルダのピン留め機能も利用できます。

### 🎬 字幕表示のネイティブ実装への移行
ライブ視聴・二画面視聴・録画視聴すべてのARIB STD-B24字幕処理を、WebViewベースの方式から **libaribcaption** ベースのネイティブ実装（JNI経由）へ移行しました。表示の安定性・応答性が向上しています。

### 📺 その他の新機能
* 録画視聴画面のUIを刷新し、十字キーでの直感的な操作とシークバー上のサムネイル表示に対応しました。
* 番組表の表示チャンネル数・表示時間幅・文字サイズをカスタマイズできるようになりました。
* 朝・昼・夕方・夜で自動的にUIのカラーパレットが変化する「時間連動テーマ」を追加しました。
* チャプター情報がある番組で、CM区間を自動的にスキップする「自動CMスキップ」機能を追加しました。
  * ご利用にはチャプター情報が必要です。KonomiTVバックエンドではサーバー側にチャプター情報が登録されている番組、EDCBバックエンドでは録画ファイルに対応する `.chapter`（TvtPlay形式）または `.chapter.txt`（Amatsukaze形式）のチャプターファイルが必要です。
* Cloudflare Zero Trust（Cloudflare Access）配下の環境にも、サービストークンを設定して接続できるようになりました。

## 🛠️ EDCBバックエンドをご利用の方へ

EDCB環境をご利用いただくには、連携スクリプト `resolver.lua` の配置が必要です。**「直接アクセス」再生だけでなく、EMWUI経由のAPI（トランスコード）再生をご利用の場合も必須**です。画質一覧の取得やAPIアクセスに使うトークンの取得元がresolver.luaになっているためです。各リリースに同梱の以下ツールで自動設定できます。

* **KomorebiConfigurator**（Windows向け）
* **setup.sh**（Linux向け。実行権限を付与してご利用ください）

使い方の詳細は同梱の `KomorebiConfigurator-Readme.txt` をご参照ください。

さらに、「直接アクセス」再生でシーンサーチのサムネイル画像を表示するには、**KomorebiThumbnailer** による事前のサムネイル生成が必要です。以下のいずれかの方法でご利用ください。

* EDCBの録画終了後実行バッチ（`PostRecEnd.bat`）に組み込み、録画完了のたびに自動生成する（推奨）
* 過去の録画ファイルをまとめて処理する一括生成バッチ・スクリプトを実行する

使い方の詳細は同梱の `KomorebiThumbnailer-Readme.txt` をご参照ください。

**検証環境**: Linuxネイティブ xtne6f版EDCB + 最新版EMWUI

## ⚠️ 既知の不具合

* **チャプタースキップ・シーク時の位置ズレについて**
  録画ファイルの直接アクセス再生時のシーク位置計算は、現状「経過時間とファイルサイズが比例する」という近似（線形補間）に基づいています。ビットレートが変動する（VBR）録画ファイルではこの近似に誤差が生じ、チャプタースキップやシークバー操作の着地位置が数秒〜十数秒程度ズレる場合があります。より正確な着地のための索引機構については、引き続き検討中です。
